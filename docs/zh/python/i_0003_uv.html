Python版本管理与虚拟环境uv工具

大纲
Are you an LLM? You can read better optimized documentation at /zh\python\i_0003_uv.md for this page in Markdown format

uv 是 Astral 团队（Ruff 那帮人）用 Rust 写的新一代 Python 工具，一个 uv 能替掉 pip + poetry + pyenv + pipx + venv + twine，官方号称比 pip 快 10–100 倍。2024 年之后新项目基本都在往这迁，老项目也能无缝切（兼容 pyproject.toml 和 requirements.txt）。

下面按「装 → 用 → 进阶」走一遍。

一、安装（三选一，推荐第一种） ​

🌟 官方脚本（最干净，不依赖已有 Python）

bash
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell，需管理员)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

装完 uv --version 能出号就行，还能 uv self update 自更新。

包管理器党

bash
brew install uv          # macOS
winget install astral-sh.uv  # Windows
scoop install main/uv    # Windows scoop

已有 Python 的环境

bash
pipx install uv     # 推荐，隔离环境不污染
pip install uv      # 也行，但功能没差

💡 官方脚本装出来是个独立二进制，没 Python 也能跑，所以哪怕你机器上还没 Python，直接脚本装也 OK。

二、核心使用：项目流（替代 poetry 那套） ​

1. 初始化项目 ​

bash
uv init myproject          # 生成 pyproject.toml + .python-version + .gitignore
cd myproject
uv init --python 3.11      # 指定 Python 版本

2. 加依赖 ​

bash
uv add fastapi uvicorn           # 生产依赖 → 写进 pyproject.toml
uv add --dev pytest ruff         # 开发依赖 → [project.optional-dependencies] dev 组
uv add "pydantic>=2"             # 带版本约束
uv remove requests               # 删依赖

每次 add 自动更新 pyproject.toml + uv.lock，不用手动 lock。

3. 同步环境（最核心命令） ​

bash
uv sync              # 按 pyproject.toml + uv.lock 装包，没 .venv 会自动建
uv sync --locked     # CI/CD 用：严格按 uv.lock 复现，不重新解析
uv sync --upgrade    # 全部升到最新允许版本
uv sync --upgrade-package pandas  # 只升 pandas

团队协作就交 pyproject.toml + uv.lock 进 Git，别人 clone 下来 uv sync --locked 一键复现。

4. 运行 ​

bash
uv run main.py                    # 在 .venv 里跑
uv run ruff check .               # 直接跑工具（不用先 activate）
uv run -m pytest                  # 等价于 python -m pytest

uv run 会自动确保依赖装好，不用手动 source .venv/bin/activate。

三、Python 版本管理（替代 pyenv） ​

bash
uv python list                    # 看可装的版本
uv python install 3.10 3.11 3.12  # 一次装多个
uv python pin 3.11                # 当前目录锁定用 3.11（写 .python-version）
uv venv --python 3.12             # 建 venv 时指定版本，没有会自动下载

📌 以前要 pyenv 做的事，现在 uv 自己就能下 CPython（甚至 PyPy），uv venv --python 3.12.0 发现本地没有就自动拉，省一层工具。

四、顺手好用的小功能 ​

🔹 单文件脚本依赖注入（写小 demo 超爽）

python
# example.py
import requests
print(requests.get("https://astral.sh"))
bash
uv add --script example.py requests
uv run example.py        # 自动在隔离环境装 requests 再跑

脚本头里会写上 # /// script 元数据，发给别人也能 uv run 直接跑。

🔹 替代 pipx 跑全局工具

bash
uv tool install black          # 装到隔离环境，全局可用 black
uvx pycowsay 'hello'           # uvx = uv tool run，临时起隔离环境跑完就扔

uvx ruff check . 这种用法基本把 pipx 替掉了。

🔹 兼容老项目的 pip 接口（不想改工作流时）

bash
uv pip install -r requirements.txt   # 直接当 turbo pip 用
uv pip compile requirements.in -o requirements.txt  # 替代 pip-compile
uv venv                                   # 替代 virtualenv

老项目零迁移成本，先把 pip 换成 uv pip 享受速度，再慢慢迁到 uv init 项目流。

五、从零起一个 FastAPI 项目的完整流程 ​

bash
uv init myapi --python 3.11
cd myapi
uv add "fastapi[standard]" uvicorn
uv add --dev pytest ruff

# 写 main.py ...
uv run uvicorn main:app --reload

整个流程不碰 pip、不碰 poetry、不碰 pyenv，一个工具全搞定。

六、uv vs 老工具链速查 ​

你想干的事以前现在 uv
装包pip installuv add / uv pip install
虚拟环境venv + activateuv sync 自动建
锁版本poetry.lock / pip-toolsuv.lock 自动生成
切 Python 版本pyenvuv python install + uv python pin
全局 CLI 工具pipxuv tool install / uvx
发 PyPI 包poetry build + twineuv build + uv publish

⚠️ 唯一还没完全追平的是：poetry 发私有仓库 + 插件生态更成熟，uv publish 对新手够用但对复杂发布场景还在赶。普通项目不用纠结。
